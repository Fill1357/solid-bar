# Solid Interface — классические панели чата для AyuGram

Плагин возвращает обычное непрозрачное оформление **верхней шапки чата** и **нижней панели ввода** в AyuGram4A. Он не меняет фон переписки, обои, цвета пузырей сообщений или настройки оформления самого чата.

## Что меняется

- Верхняя панель: отключается blur у `ActionBar`; сохраняется цвет, заданный текущей темой.
- Нижняя панель: `ChatActivityEnterView.allowBlur` выключается; используется штатная тематическая заливка поля ввода.
- Остальные экраны и глобальные параметры размытия не затрагиваются.
- Для возврата исходного поведения при выгрузке плагина сохраняются прежние значения затронутых флагов.

## Как применить

1. Установи и включи плагин.
2. Открой нужный чат.
3. Открой меню действий чата и выбери **«Классические панели чата»**.
   Альтернативно можно открыть настройки плагина и нажать **«Применить классические панели»**.
4. Если экран чата был открыт ещё до загрузки плагина, применение через меню/настройки всё равно выполнит поиск текущего `ChatActivity`.

Если плагин загрузился, когда чат уже открыт, он также пробует применить оформление автоматически.

## Сборка

Проект собирает Kotlin-логику в DEX и встраивает её в Python-плагин:

```sh
./gradlew :buildDexRelease
python3 build_plugin.py
```

Для локальной сборки нужны JDK, Android SDK и compile-classpath AyuGram, указанный в `gradle.properties`. GitHub Actions workflow `Release` подготавливает минимальный stub `Telegram.stripped.jar`, собирает DEX и формирует файл `.plugin`.

## Важное ограничение

Изменение проверено по исходникам AyuGram4A, приложенным к проекту, и Kotlin-код прошёл отдельную проверку синтаксиса. Полноценный запуск на устройстве и проверка внешнего вида требуют сборки DEX и тестирования именно на AyuGram 12.10.6 (71129). Если структура классов в установленной сборке отличается от приложенных исходников, понадобится адаптация.
